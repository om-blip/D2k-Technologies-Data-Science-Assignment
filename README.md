# Credit Card Customer Analysis

## Project Overview
This project performs a comprehensive analysis of credit card customer data to uncover patterns in customer behavior, segment customers for targeted marketing, and predict customer churn. It is divided into four main parts:
1. **Data Exploration and Preprocessing**: Cleaning and preparing the data for analysis.
2. **Data Analysis and Visualization**: Extracting insights through detailed data exploration and visualizations.
3. **Customer Segmentation**: Grouping customers based on their credit card usage and demographics using clustering techniques.
4. **Predictive Modeling**: Building and evaluating models to predict customer churn.

## Dataset
The project utilizes a credit card customer dataset containing various demographic and usage features, including:
- Customer demographics (Age, Gender, Marital Status, Income, etc.)
- Credit card usage statistics (Credit Limit, Balance, Transactions, etc.)
- Customer status (Existing or Attrited)

## Project Objectives
- Understand customer demographics and their relationship with credit card usage.
- Identify patterns in credit card usage across different customer groups.
- Segment customers into meaningful clusters for targeted marketing strategies.
- Predict customer churn using different machine learning models and evaluate their performance.
